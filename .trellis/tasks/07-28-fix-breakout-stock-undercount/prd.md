# Fix breakout stock undercount

## Goal

修正“涨停前高突破”统计对重新进入连板池股票的漏算。统计只比较前后涨停，不判断断板期间是否曾以非涨停方式突破。

## Requirements

* 候选股票必须在目标日进入涨停池。
* 股票此前必须存在一段二连板及以上的连板记录。
* 前一段连板结束日至目标日之间至少间隔一个交易日。
* 目标日涨停价必须大于或等于前一段连板期间的最高涨停价。
* 目标日是否进入连板池不得影响候选资格。
* 如果目标日前最近的历史连板记录属于当前重新连板且与目标日没有间隔，继续向前寻找最近一段已经断开的连板作为比较基准。
* 保持现有 5、6-10、11-30、31-60 个交易日分组及展示格式。
* 展示使用“距前段连板结束 N 个交易日”，避免把重新连板期间误称为断板日。
* 目标日涨停价等于前高时显示“涨停触及前高”；严格高于时显示“突破 X%”。

## Acceptance Criteria

* [x] 断板后重新二连板且目标日突破旧连板高点的股票会被统计。
* [x] 断板后重新三板、四板且目标日不低于旧连板高点的股票会被统计。
* [x] 未进入目标日涨停池的股票不会被统计。
* [x] 目标日涨停价等于旧连板高点的股票会被统计，低于时不会被统计。
* [x] 没有至少一个交易日间隔的连续晋级股票不会被统计。
* [x] 原有时间窗口展示测试继续通过。
* [x] 等于前高与严格突破使用不同且准确的展示文案。

## Definition of Done

* 添加或更新计算层单元测试。
* 相关测试、代码规范检查通过。
* 不改变飞书展示字段和分组文案。

## Technical Approach

移除 `_build_breakout_stocks` 中基于目标日 `ContinuousLimitUp` 的提前排除。历史链段从近到远检查，跳过与目标日没有间隔的当前连板段，选择最近一段已经断开的连板作为前高基准。使用内存 SQLite 覆盖等高重新二板、三板、四板纳入与从未断板的连续晋级排除场景。

## Decision (ADR-lite)

**Context**: 当前实现把目标日所有连板股排除，导致断板后重新二板或更高板的突破股漏算。

**Decision**: 目标日连板身份不参与过滤，只按前后涨停及价格关系判断。

**Consequences**: 重新连板股票会正常进入统计；断板期间是否已经突破旧高不在本任务判断范围内。

## Out of Scope

* 不检查断板期间的日内高价或收盘价。
* 不纳入历史仅有首板、没有二连板记录的股票。
* 不修改交易日数据源、复权方式或前高定义。
